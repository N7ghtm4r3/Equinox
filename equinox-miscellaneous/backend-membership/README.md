# Equinox Backend Membership

An optional member management extension for **Spring Boot** backends built with [Equinox Backend](../../equinox-backend/README.md).

## Scope

This module is intended to extend Equinox Backend with member management capabilities. Applications can opt into it when they need those capabilities, while Equinox Backend remains independently usable.

## Development status

The module currently contains its Gradle and Maven publishing configuration. Member management APIs and the dependency on Equinox Backend have not been implemented yet.

The configured Maven coordinates are `io.github.n7ghtm4r3:equinoxmisc-backend-membership:1.0.0`.

## Requirements

- Java 21
- Equinox Backend (the required module dependency is still to be configured)
